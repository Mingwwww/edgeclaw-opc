EdgeClaw 网页版一键安装后会提供 `pilotdeck` 命令。

## 常用命令

```bash
pilotdeck
```

启动服务，默认访问：

```text
http://localhost:3001
```

```bash
pilotdeck status
```

查看配置文件、数据目录和当前状态。

```bash
pilotdeck --port 8080
```

使用自定义端口启动。

```bash
pilotdeck help
```

查看完整命令帮助。
