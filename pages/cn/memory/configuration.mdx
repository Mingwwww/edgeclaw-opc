Memory 的配置同样来自 `~/.edgeclaw/config.yaml`。

## 继承主模型

最简单的方式是继承主模型：

```yaml
memory:
  enabled: true
  model: inherit
```

## 使用独立模型

如果希望 Memory 使用更便宜或更快的模型，可以先在 `models.providers` 和 `models.entries` 中定义模型，再让 `memory.model` 指向对应 id。

```yaml
models:
  entries:
    memory-small:
      provider: edgeclaw
      name: your-memory-model
memory:
  enabled: true
  model: memory-small
```
