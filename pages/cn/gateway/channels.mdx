EdgeClaw Gateway 设计上支持多种渠道。不同渠道的认证方式、回调方式和用户访问控制不同。

## 当前计划覆盖的渠道

| 渠道 | 说明 | 状态 |
| --- | --- | --- |
| Feishu / Lark | 飞书机器人或事件通道 | 待补教程 |
| Telegram | Bot Token 接入 | 待补教程 |
| Discord | Bot Token 接入 | 待补教程 |
| Slack | Bot Token / App Token | 待补教程 |
| WeCom / DingTalk | 企业通讯工具 | 待补教程 |
| Webhook | HTTP 回调入口 | 待补教程 |
| API Server | 程序化调用入口 | 待补教程 |

## 后续补充方向

每个渠道会单独补：申请凭证、配置 YAML、启动方式、测试方法和常见错误。
