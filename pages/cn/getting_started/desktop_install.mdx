## 标准安装流程

1. 下载 <a href="https://github.com/Mingwwww/edgeclaw-opc/releases/download/v0.1.5/EdgeClaw-0.1.5-arm64.dmg" style={{color: "#2563EB", textDecoration: "none"}}>EdgeClaw-&lt;version&gt;-arm64.dmg</a>。
2. 双击 DMG 挂载。
3. 将 `EdgeClaw.app` 拖到 `Applications`。
4. 从 Launchpad、Finder 或 Dock 启动 EdgeClaw。

如果第 4 步提示“无法启动 EdgeClaw 应用程序”，且窗口一闪消失，通常是通过飞书、微信等沙盒 IM 收到 DMG 后触发了 macOS Gatekeeper 的额外限制。
